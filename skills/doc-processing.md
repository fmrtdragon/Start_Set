# 文档与数据处理技能

Markdown/CSV/JSON 等格式文件的读取、转换、合并、图片处理规范。

**触发条件**：用户要求以下任一操作时激活：
- 读取/分析/解析 Markdown 表格
- 合并多个 Markdown 表格
- Markdown 转 CSV
- 下载 MD 中引用的在线图片并转为本地引用
- 格式化 Verilog/SystemVerilog 代码
- 处理 JSON/YAML/CSV 等结构化数据文件

## 1. 文件探索

### 1.1 目录分析

- 先用 `ls -la` 查看顶层结构，再用 `find -type f` 了解全貌
- 识别文件类型：源码（.sv/.v/.c）、数据（.md/.csv/.txt）、配置（.cmd/.cfg）、脚本（.sh/.py）
- 按功能/模块分组理解项目组织

### 1.2 逐层深入

- 先读配置和顶层文件理解项目意图，再深入具体实现
- 对大型文件（>200 行）先读头和尾，中间采样，最后按需读取

## 2. Markdown 表格处理

### 2.1 解析

- 识别表头行、分隔行（`|---|---|`）、数据行
- 跳过空行和非表格内容（如节标题）
- 提取单元格时去首尾 `|`，按 `|` 切分后 strip 空白

### 2.2 转 CSV

- 表头作 CSV 第一行，数据行直接写入
- 多表格文件以空行分隔各表

### 2.3 合并

- 两表按行一一对应合并，先验证行数一致
- 不一致时定位差异行并告知用户
- 合并后自动计算各列最大宽度并对齐

### 2.4 对齐

- 分隔行 `---` 宽度 = 列内容最大宽度 + 2（两侧空格与 `| content |` 格式一致）
- 数值列右对齐、文本列左对齐、表头左对齐
- 类型通过采样自动检测（>50% 非占位值可解析则判定为该类型）

## 3. 图片处理

### 3.1 在线图片下载

- 扫描 MD 中 `![alt](URL)` 语法，提取在线图片 URL
- 下载到本地指定目录，保留原始文件名或按顺序命名
- 下载成功后将原文引用改为相对路径 `../Picture/filename`

### 3.2 目录结构

```
output/
├── Picture/     # 下载的图片
└── Md/          # 更新引用后的 MD 文件
```

## 4. Verilog/SystemVerilog 代码格式化

### 4.1 缩进

- 统一 4 空格缩进
- 预编译指令随嵌套层级缩进

### 4.2 端口声明

- 显式 `wire` 关键字，同列对齐

### 4.3 begin/end

- 单语句 `if`/`for` 省略冗余 `begin..end`

### 4.4 属性声明

- `(* ram_style *)` 等属性与声明分行

### 4.5 格式化后验证

- 格式化完成后逐项检查是否引入语法问题（模块名、宏依赖、时序逻辑、循环语法）
