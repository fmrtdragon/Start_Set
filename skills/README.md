StartAI 技能文件，每个文件封装一个独立领域的操作规范。触发条件决定何时激活对应技能。

| 文件 | 领域 | 触发条件 | 来源 |
|------|------|----------|------|
| `script-development.md` | 脚本编写全流程 | 用户要求编写/生成/调试/修改代码或脚本 | merge_sram_tables / sram_1prf_select / md_image_downloader / sram_1prf_batch_test 等脚本的迭代经验 |
| `git-workflow.md` | Git 操作规范 | 用户要求执行 commit/push/pull/merge 等 Git 操作 | 多次 Git init/commit/push/remote 操作中的错误和修复经验 |
| `doc-processing.md` | 文档与数据处理 | 解析/合并 MD 表格、MD→CSV、图片下载、Verilog 格式化、结构化数据处理 | Markdown 表格解析/合并/对齐、图片下载、CSV 转换、Verilog 格式化等 |
